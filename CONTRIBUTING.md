# Contributing

Thanks for your interest in VitaGuard.

Before contributing:
1. Read the repository documentation and hardware safety notes.
2. Discuss substantive technical changes in an issue before opening a pull request.
3. Do not upload secrets, worker health data, confidential site data or unlicensed third-party material.
4. Include test steps, hardware revision, firmware commit and results when changing safety-critical behavior.
5. Keep diagrams synchronized with the tested hardware and release code.
6. Avoid unsupported claims about accuracy, predictive lead time, range or battery performance.
7. Confirm with the project maintainers that public collaboration is permitted under the current IP/patent strategy.

For a safety-related change, include failure behavior as well as the expected “happy path.”
