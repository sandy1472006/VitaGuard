# Roadmap and Configurable Extensions

This roadmap separates optional extensions from core features described in the current VitaGuard 2.0 specification.

## Deployment extensions
- Additional sensor modules for deployments with different hazard profiles.
- Multi-worker fleet management and role-based dashboard access.
- Additional radio or gateway configurations tailored to site infrastructure.
- Integration with site QC, incident reporting, EHS or maintenance systems.
- Enclosure refinement based on field wearability and serviceability.

## Security and data governance
- Document encryption key management and rotation.
- Define worker consent, data retention, report access and audit policy.
- Review tamper-evident audit logging requirements where needed.
- Validate firmware update authenticity and recovery.

## Engineering maturity
- Formalize a production PCB revision.
- Improve connector strain relief and enclosure serviceability.
- Validate thermal separation and airflow around the gas module.
- Run site-specific RF, environmental, battery, wearability and false-alarm tests.
- Determine required certification before deployment in regulated or hazardous environments.

## Scope note
Only list an item as “future” if it is not already implemented in the release. If these capabilities are completed in the current build, move them to the main architecture documentation and attach the implementation version and evidence.
